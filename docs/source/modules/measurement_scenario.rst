Measurement scenario module
===========================

Module description
------------------

The Measurement Scenario class (necessary for the :class:`EmpiricalModel <CF.empirical_model.EmpiricalModel>` class) is storing the variables linked to an
experiment described by `Abramsky and Brandenburger <https://iopscience.iop.org/article/10.1088/1367-2630/13/11/113036>`_.
At the moment again this class mainly serve as a placeholder for 3 variables, X, O and M but it has possibilities to be
easily extended. It also implements the :meth:`incidence_matrix <CF.measurement_scenario.MeasurementScenario.incidence_matrix>` property, which is useful.
